# Atlas Launcher 1.7.1

**[Télécharger AtlasLauncherSetup.exe](https://github.com/Dono1402/WotLK-Launcher/releases/download/v1.7.1/AtlasLauncherSetup.exe)**

Cette version corrige une régression du système de mise à jour introduite en 1.6.0.

**Depuis la version 1.6.0 ou 1.7.0, utilisez l’installateur pour cette mise à niveau.** Fermez Atlas Launcher, lancez AtlasLauncherSetup.exe et conservez le dossier d’installation habituel. Aucune désinstallation préalable n’est nécessaire. Le bouton de mise à jour des anciennes versions ne peut pas corriger son propre mécanisme défectueux.

La boutique et le changement de nom de la version 1.7.0 sont conservés.

[English release notes](https://github.com/Dono1402/WotLK-Launcher/releases/download/v1.7.1/PATCH-NOTES.en.md)

Atlas Launcher 1.7.1 corrige un échec de mise à jour après le téléchargement.

## Mise à jour du launcher

- Correction du contrôle Windows qui empêchait le launcher de reconnaître son outil de mise à jour.
- Les vérifications de signature et d’intégrité des téléchargements restent actives.

## Installation de cette correction

- Depuis la version 1.6.0 ou 1.7.0, fermez Atlas Launcher et lancez l’installateur 1.7.1 téléchargé depuis la page de la release.
- Choisissez le dossier d’installation habituel. Aucune désinstallation préalable n’est nécessaire.
