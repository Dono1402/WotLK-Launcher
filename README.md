# Atlas Launcher

Le launcher Windows du royaume **Arthas**, pour **World of Warcraft: Wrath of the Lich King Classic**.

**[Télécharger Atlas Launcher pour Windows](https://github.com/Dono1402/WotLK-Launcher/releases/latest/download/AtlasLauncherSetup.exe)**

Windows 64 bits · Version actuelle : **1.6.0**

## Installation

1. Télécharge **AtlasLauncherSetup.exe** avec le lien ci-dessus.
2. Ouvre l’installateur et suis les étapes à l’écran.
3. Lance **Atlas Launcher**, puis connecte-toi ou crée ton compte.
4. Installe le jeu depuis le launcher, ou sélectionne le dossier de ton client compatible déjà installé, puis clique sur **Jouer**.

Si Atlas Launcher est déjà installé, les nouvelles versions sont proposées directement dans l’application.

## Ce que tu peux faire

- Installer, mettre à jour et vérifier les fichiers du jeu.
- Parcourir le catalogue d’addons et gérer leur installation.
- Consulter tes personnages, leur équipement et l’armurerie 3D.
- Retrouver tes amis, voir leur présence et consulter leurs profils.
- Discuter en privé ou en groupe, partager des fichiers et échanger avec les joueurs en jeu.
