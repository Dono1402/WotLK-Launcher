# Atlas Launcher 1.8.1

Fixes the Windows restart after a launcher update.

## Updates

- Fixed a Windows access-denied error that prevented the launcher from restarting after installation and caused an automatic rollback to the previous version.
- The launcher restarts with your own user account, without administrator rights.
- Update logs now retain the Windows error code to help diagnose failures.

## If your update is stuck

- Fully close Atlas Launcher, then run the 1.8.1 installer over your existing installation. Your settings are preserved.
- This one-time installation replaces the faulty updater in the previously installed version.
- Includes all features introduced in 1.8.0.
