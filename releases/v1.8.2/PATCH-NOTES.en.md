# Atlas Launcher 1.8.2

Fixes Windows shortcuts, the Atlas icon and uninstall cleanup.

## Installation and icons

- Desktop and Start menu shortcuts are no longer incorrectly disabled when Windows shell folders have shared permissions.
- Installation and launcher updates notify Windows of icon changes so it can replace the cached old artwork with the Atlas logo.

## Uninstallation

- Old updater files are removed so the empty Atlas Launcher installation directory can be deleted.
- Atlas settings, game files and unrecognized additional files are preserved. The uninstaller explains when additional files keep its directory from being removed.
- Use the 1.8.2 installer to receive the corrected uninstaller as well.
