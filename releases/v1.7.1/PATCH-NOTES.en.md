# Atlas Launcher 1.7.1

Atlas Launcher 1.7.1 fixes an update failure after the download.

## Launcher update

- Fixed a Windows check that prevented the launcher from recognizing its update helper.
- Download signature and integrity checks remain active.

## Installing this fix

- From version 1.6.0 or 1.7.0, close Atlas Launcher and run the 1.7.1 installer downloaded from the release page.
- Choose the usual installation folder. No prior uninstall is required.
